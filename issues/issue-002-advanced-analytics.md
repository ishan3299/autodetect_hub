# Issue: Advanced Analytics & Filtering Features

**ID**: #002
**Status**: Open
**Assignee**: @ishan3299
**Labels**: feature, enhancement

## Description
Users need better insights into the threat data and easier ways to sift through thousands of indicators.

## Objectives
- Integrate Chart.js for visual analytics on the dashboard.
- Implement "Indicators by Type" and "Top Threat Sources" charts.
- Add dynamic filtering (Source, Type) to the Indicators table.
- Add CSV Export functionality.

## Acceptance Criteria
- [ ] Dashboard displays 2 interactive charts.
- [ ] Indicators table can be filtered by Source and Type.
- [ ] "Export CSV" button downloads the currently filtered view.
